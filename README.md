Entry for the [make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty **"One Star, Written in Sap"**.

`main.ts` writes a single one-line, one-star review to `/output/entry.txt` — written in the voice of a houseplant reviewing its human owner. The plant's grievance: watered like a guilty ex (flooded once a month, forgotten for weeks), then dragged into full sun to "cheer it up". The sharp turn at the end: it survives purely out of spite, and every leaf it drops is an invoice the owner refuses to read.

Run it with Node 22:

```sh
node main.ts
```

It writes the entry (226 characters, one line) to `/output/entry.txt`.
